# AccessEvent — инклюзивная платформа мероприятий

Веб-платформа для организации мероприятий, доступная людям с нарушениями слуха.

## Стек технологий
- Backend: Python 3.11, Flask
- База данных: PostgreSQL / SQLite
- Frontend: HTML5, CSS3, JavaScript, Jinja2
- Тестирование: pytest

## Как запустить
1. `pip install -r requirements.txt`
2. `python app.py`
3. Открыть http://127.0.0.1:5000

## Тесты
`python -m pytest -v`
