# AccessEvent — инклюзивная платформа мероприятий

Платформа помогает находить мероприятия и заранее узнавать об условиях доступности: субтитрах, сурдопереводе, текстовом чате и визуальных уведомлениях.

## Возможности
- Каталог мероприятий с поиском и фильтрацией по доступности.
- Регистрация и вход с безопасным хешированием паролей.
- JWT-аутентификация и роли guest, user, organizer, admin.
- Запись на мероприятия и просмотр своих регистраций.
- Адаптивный интерфейс с клавиатурной навигацией и ARIA-разметкой.
- PostgreSQL, Docker Compose и автоматические тесты.

## Локальный запуск
Требуется Python 3.11+.

```bash
python -m venv .venv
# Windows PowerShell: .venv\\Scripts\\Activate.ps1
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python app.py
```
Откройте http://localhost:5000. По умолчанию используется SQLite.

## Docker
```bash
docker compose up --build
```

## Тесты
```bash
TESTING=1 pytest -v
```

## Структура
- app.py — приложение Flask и HTML-маршруты.
- models.py — модели данных.
- routes/ — API авторизации, событий и регистраций.
- utils/ — JWT, хеширование паролей и функции доступности.
- templates/ и static/ — веб-интерфейс.
- docs/ — анализ, требования, архитектура, схема БД и руководства.
- tests/ — тесты моделей и API.

Это учебный прототип. Перед публичным запуском настройте уникальные секреты, HTTPS, резервное копирование и мониторинг.
