# AccessEvent — День 4 (интерфейс)

**Автор:** Коновалова Катя, группа 22-ИС.

В этой папке находятся отдельные файлы для открытия в Visual Studio Code:

- `index.html` — структура страницы;
- `style.css` — оформление и адаптация для телефона;
- `script.js` — поиск мероприятий и демонстрационные уведомления.

## Как открыть

1. Откройте папку проекта в Visual Studio Code.
2. Откройте файл `index.html` в браузере или запустите его через расширение Live Server.
3. Попробуйте поиск по названию и кнопки «Записаться».

Это самостоятельный демонстрационный интерфейс для задания 4-го дня. Кнопка записи показывает уведомление и не сохраняет данные на сервере. Основное Flask-приложение находится в корне репозитория.
