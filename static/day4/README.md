# День 4. Фронтенд и Docker

## Описание проекта

AccessEvent — платформа инклюзивных мероприятий. Проект помогает пользователям находить мероприятия с учётом доступности площадки.

## Структура проекта

```text
static/day4/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Функциональность

- Просмотр списка мероприятий.
- Поиск мероприятий по названию.
- Фильтрация по доступности площадки.
- Сброс фильтров.
- Отображение количества найденных мероприятий.
- Демонстрационное уведомление при нажатии кнопки «Записаться».
- Адаптивный дизайн для мобильных устройств.
- Раздельные HTML, CSS и JavaScript файлы.

## Запуск проекта

1. Откройте папку `static/day4/`.
2. Найдите файл `index.html`.
3. Откройте его в браузере.
4. Проверьте поиск, фильтры и кнопку «Записаться».

## Важная информация

Запись на мероприятие работает в демонстрационном режиме. Данные не сохраняются в базе данных и не отправляются на сервер.
