# День 4 — фронтенд

Учебная страница списка мероприятий с поиском по названию, фильтром доступности площадки, сбросом фильтров и демонстрационным сообщением при нажатии «Записаться».

## Запуск
Откройте `index.html` в браузере. HTML, CSS и JavaScript находятся в отдельных файлах.

**Важно:** запись демонстрационная — данные не сохраняются и не отправляются на сервер.
