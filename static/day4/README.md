# AccessEvent — День 4 (интерфейс)

**Автор:** Коновалова Катя, группа 22-ИС.

В папке `static/day4/` находятся отдельные файлы демонстрационной страницы:

- `index.html` — структура страницы;
- `style.css` — оформление, карточки, адаптация для телефона и состояния фокуса;
- `script.js` — поиск, фильтр по доступности, сброс фильтра и визуальные уведомления.

## Как открыть

1. Скачайте репозиторий или откройте его в Visual Studio Code.
2. Откройте `static/day4/index.html` в браузере или запустите его через расширение Live Server.
3. Попробуйте поиск по названию, фильтр доступности и кнопки «Выбрать мероприятие».

Это самостоятельный демонстрационный интерфейс для задания 4-го дня. Кнопки показывают уведомления и не сохраняют данные на сервере. Основное Flask-приложение находится в корне репозитория.
