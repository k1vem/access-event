# AccessEvent — День 4

**Автор:** Коновалова Катя, группа 22-ИС.

Файлы демонстрационной страницы:

- `index.html` — структура интерфейса;
- `style.css` — стили и адаптация для телефона;
- `script.js` — поиск, фильтрация и визуальные уведомления.

## Запуск

Откройте `static/day4/index.html` в браузере или через расширение Live Server в Visual Studio Code. Кнопки выбора показывают демонстрационное уведомление; данные не отправляются на сервер.
