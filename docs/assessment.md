# Итоговая оценка проекта

AccessEvent — учебный прототип инклюзивной платформы мероприятий. В текущем коде есть каталог и фильтрация, регистрация и вход, хеширование паролей, JWT, ролевые проверки, запись на события, сообщения, отзывы, уведомления, адаптивные шаблоны и автоматические тесты. Docker Compose предназначен для запуска Flask и PostgreSQL.

## SWOT-анализ

| Сильные стороны (Strengths) | Слабые стороны (Weaknesses) |
|---|---|
| Простой стек Python/Flask и понятная структура модулей | Нет миграций схемы БД и полноценной панели администратора |
| Хеширование паролей и JWT | Нет восстановления пароля и подтверждения email |
| Тестовая конфигурация SQLite и GitHub Actions | Визуальные уведомления в браузере не заменяют полноценную службу напоминаний |

| Возможности (Opportunities) | Угрозы (Threats) |
|---|---|
| Календарь, расширенные фильтры доступности, импорт событий | Слабые или повторно используемые секреты |
| Email-уведомления и подтверждение email | Сбои БД без резервных копий |
| Проверки доступности по WCAG и пользовательское тестирование | Публичный запуск без HTTPS, мониторинга и ограничения частоты запросов |

## Направления модернизации
1. Добавить миграции базы данных (например, Alembic/Flask-Migrate).
2. Реализовать подтверждение email и восстановление пароля.
3. Расширить тесты интеграционными сценариями для записи, чата и уведомлений.
4. Добавить CI-проверку контейнера и документировать публикацию образа в GHCR.
5. Провести аудит доступности с клавиатурой, скринридером и проверкой контрастности.

## Проверка перед сдачей
- Выполнить python -m pytest -v.
- Убедиться, что все обязательные GitHub Actions завершились успешно.
- Проверить docker compose up --build и сценарий регистрации → вход → запись → сообщение → уведомление.
- Проверить отсутствие реальных секретов в истории Git.

Эта оценка описывает учебный прототип, а не подтверждение готовности к промышленной эксплуатации.
