# Итоговая оценка проекта AccessEvent

AccessEvent — учебный прототип инклюзивной платформы мероприятий. Реализованы каталог мероприятий, поиск, регистрация и вход, хеширование паролей, JWT-аутентификация, ролевой доступ, запись на мероприятия, шаблоны интерфейса, модели данных и автоматические тесты.

## Ограничения

- Нет подтверждения email и восстановления пароля.
- Email/SMS-уведомления не подключены; уведомления хранятся в приложении.
- Полноценная административная панель и загрузка материалов требуют дополнительной реализации.
- Для production-развёртывания нужны HTTPS, уникальные секреты, резервное копирование, мониторинг, миграции базы данных и ограничение частоты запросов.

## Проверка

Запуск тестов: `python -m pytest -v`.

Проверка локального сервера: `python app.py`, затем открыть `http://127.0.0.1:5000/health`.
