# Итоговая оценка проекта

AccessEvent — учебный прототип инклюзивной платформы мероприятий. Реализуются каталог, поиск, регистрация и вход, хеширование паролей, JWT, ролевой доступ организаторов, запись на события, адаптивные шаблоны, PostgreSQL через Docker Compose и тесты.

Ограничения: нет подтверждения email, восстановления пароля, реальных email/SMS-уведомлений, полноценной панели организатора и миграций БД. Перед публичным запуском нужны HTTPS, уникальные секреты, резервное копирование, мониторинг и ограничение частоты запросов.
