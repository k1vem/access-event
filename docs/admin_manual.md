# Руководство администратора

## Требования
- Python 3.11+ для локального запуска.
- Docker Engine и Docker Compose для контейнерного запуска.
- Git для получения обновлений проекта.

## Локальный запуск
1. Перейдите в корень репозитория.
2. Создайте виртуальное окружение: python -m venv .venv.
3. Активируйте окружение и установите зависимости: python -m pip install -r requirements.txt.
4. При необходимости скопируйте .env.example в .env и замените секреты.
5. Запустите python app.py и откройте http://127.0.0.1:5000.

По умолчанию локальный запуск использует SQLite. Чтобы подключить PostgreSQL, задайте DATABASE_URL.

## Запуск Docker Compose
Из корня проекта выполните docker compose up --build. Приложение будет доступно по адресу http://127.0.0.1:5000. Для остановки нажмите Ctrl+C и выполните docker compose down. Команда docker compose down -v удаляет том с данными БД — используйте её только если данные больше не нужны.

## Роли
- guest — просмотр открытого каталога;
- user — регистрация на события, сообщения, отзывы и уведомления;
- organizer — создание мероприятий и обработка заявок на собственные мероприятия;
- admin — роль предусмотрена в API, но полноценная административная панель не входит в текущий прототип.

## Обслуживание и диагностика
- Проверка приложения: GET /health.
- Автотесты: python -m pytest -v.
- Проверяйте GitHub Actions после каждого изменения.
- Для публичного запуска используйте уникальные секреты, HTTPS, резервное копирование, мониторинг и актуальные зависимости.
- Не публикуйте файл .env и не храните в репозитории настоящие пароли или токены.
