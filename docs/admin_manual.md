# Руководство администратора

Для локального запуска установите Python 3.11+, создайте виртуальное окружение, выполните pip install -r requirements.txt и запустите python app.py.

Docker: docker compose up --build, затем откройте http://localhost:5000.

Роли: guest — просмотр; user — регистрация; organizer — создание событий; admin — административные действия. Для публичного развёртывания используйте уникальные секреты, HTTPS, резервные копии и мониторинг.
