# План презентации AccessEvent

**Автор:** Коновалова Катя, группа 22-ИС

В репозитории поддерживается текстовый план слайдов; готовая презентация PowerPoint подготовлена отдельно как файл `AccessEvent_presentation.pptx`.

1. **Титульный слайд:** AccessEvent — инклюзивная платформа мероприятий.
2. **Проблема и цель:** доступная информация и визуальные статусы для людей с нарушениями слуха.
3. **Требования и пользователи:** сценарии участника и организатора.
4. **Архитектура и данные:** frontend, Flask API, JWT, SQLAlchemy, PostgreSQL/SQLite.
5. **Реализация:** каталог, авторизация, заявки, сообщения, отзывы и уведомления.
6. **Тестирование и развёртывание:** pytest, GitHub Actions, Docker Compose.
7. **Оценка и развитие:** SWOT, ограничения прототипа и направления модернизации.
