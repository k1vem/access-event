# Тезисы выступления — AccessEvent

**Автор:** Коновалова Катя, группа 22-ИС

## План на 5–7 минут

### 1. Проблема и цель (около 30 секунд)
AccessEvent — учебная веб-платформа для организации мероприятий с учётом потребностей людей с нарушениями слуха. Важная информация передаётся текстом и визуальными статусами, а не только звуковыми сигналами.

### 2. Требования и пользователи (около 1 минуты)
Основные пользователи — участник, организатор и администратор. Участник просматривает каталог, фильтрует мероприятия по доступности и отправляет заявку. Организатор создаёт мероприятие и обрабатывает заявки. Система также поддерживает текстовые сообщения, отзывы и уведомления.

### 3. Архитектура и данные (около 1 минуты)
Frontend построен на HTML, Jinja2, CSS и JavaScript. Backend использует Python, Flask и REST-маршруты. SQLAlchemy связывает приложение с базой данных: PostgreSQL используется в Docker Compose, а SQLite — для изолированных автоматических тестов. Основные сущности — пользователи, мероприятия, регистрации, сообщения, уведомления и отзывы.

### 4. Демонстрация (около 2 минут)
Показать главную страницу и каталог. Затем зарегистрировать пользователя, войти, найти мероприятие и проверить его доступность. Для сквозной демонстрации использовать пользователя-организатора, создать мероприятие, записать второго пользователя, отправить сообщение и проверить уведомление. Если часть действий отсутствует в UI, показать соответствующий API-запрос и не выдавать его за готовую экранную функцию.

### 5. Тестирование и качество (около 1 минуты)
Автоматические тесты проверяют состояние сервиса, регистрацию и вход, ответы API, ролевой доступ, сериализацию моделей и сопоставление функций доступности. Показать фактический результат python -m pytest -v и вкладку GitHub Actions; сообщать только подтверждённые числа и статусы.

### 6. Оценка и развитие (около 1 минуты)
Сильные стороны — простой стек, хеширование паролей, JWT, Docker и тесты. Дальнейшие шаги: миграции БД, подтверждение email, восстановление пароля, расширенные интеграционные тесты, аудит доступности и мониторинг.
