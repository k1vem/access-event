# Руководство пользователя

## 1. Открытие платформы
Запустите приложение по инструкции в README или откройте адрес, предоставленный администратором. При локальном запуске это http://127.0.0.1:5000.

## 2. Просмотр и поиск мероприятий
1. Откройте раздел «Мероприятия».
2. Введите часть названия в поле поиска.
3. Выберите доступную функцию (например, субтитры или текстовый чат), если требуется.
4. Нажмите кнопку поиска и откройте карточку подходящего мероприятия.
5. Перед записью проверьте дату, место и описание доступности.

## 3. Создание аккаунта и вход
1. Откройте страницу регистрации.
2. Укажите имя пользователя, email и пароль длиной не менее 8 символов.
3. После регистрации откройте страницу входа и используйте email с паролем.
4. Не передавайте пароль и токен другим людям.

## 4. Запись на мероприятие
После входа используйте действие записи на странице мероприятия. Заявка получает статус ожидания (pending). Организатор может подтвердить или отменить её; актуальный статус возвращается API.

## 5. Сообщения, отзывы и уведомления
- На странице мероприятия можно использовать текстовый чат, если пользователь авторизован.
- Для отзыва требуется вход; оценка должна быть от 1 до 5.
- Уведомления отображаются визуально. Звуковой сигнал не является обязательным способом получения информации.

## 6. Доступность
Используйте клавиатуру для перемещения между ссылками и полями. Подписи полей помогают понять назначение ввода. Если информация о доступности события неполная, уточните её у организатора до посещения.

Примечание: набор доступных действий зависит от текущей версии интерфейса. Некоторые операции доступны только через документированный API.
