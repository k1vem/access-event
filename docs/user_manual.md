# Руководство пользователя

1. Откройте главную страницу и каталог мероприятий.
2. Используйте поиск и фильтр доступности.
3. Создайте аккаунт: имя пользователя, email, пароль от 8 символов.
4. Войдите и нажмите «Записаться» в карточке мероприятия.
5. В профиле просматривайте регистрации.

Основные действия доступны с клавиатуры. Функции доступности указаны в карточке события. Не передавайте токен другим людям.
