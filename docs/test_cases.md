# Тест-кейсы AccessEvent

Тесты API и моделей запускаются командой `python -m pytest -v` из корня репозитория. В CI тестовая конфигурация использует SQLite in-memory.

## Тест-кейсы

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| TC-01 | GET /health | HTTP 200, status=ok |
| TC-02 | Регистрация с корректными данными | HTTP 201 и JWT |
| TC-03 | Неполная регистрация | HTTP 400 |
| TC-04 | Повторный email или username | HTTP 409 |
| TC-05 | Успешный вход | HTTP 200 и JWT |
| TC-06 | Неверный пароль | HTTP 401 |
| TC-07 | GET /api/events | HTTP 200 и JSON-массив |
| TC-08 | Несуществующее мероприятие | HTTP 404 |
| TC-09 | Запись без токена | HTTP 401 |
| TC-10 | Создание мероприятия обычным пользователем | HTTP 403 |
| TC-11 | Проверка хеширования пароля | Пароль не хранится открытым текстом |
| TC-12 | Сериализация пользователя | В ответе отсутствуют пароль и password_hash |
| TC-13 | Сериализация мероприятия | Присутствуют название и сведения о доступности |
| TC-14 | Сопоставление требований доступности | Сравнение без учёта регистра |
| TC-15 | Доступность UI | У форм есть подписи, уведомления доступны для скринридера |

## Чек-лист ручной приёмки

- [ ] Главная страница открывается по адресу `http://127.0.0.1:5000`.
- [ ] Страницы каталога, входа и регистрации возвращают HTTP 200.
- [ ] Регистрация возвращает токен и не раскрывает хеш пароля.
- [ ] Вход с неверным паролем возвращает понятную ошибку.
- [ ] Каталог доступен без авторизации.
- [ ] Защищённые маршруты отклоняют запрос без Bearer-токена.
- [ ] Пользователь без роли организатора не может создавать мероприятия.
- [ ] Сообщения интерфейса являются визуальными и имеют ARIA-атрибуты.
- [ ] `docker compose up --build` запускает web и PostgreSQL.
- [ ] GitHub Actions завершает обязательные проверки без ошибок.
